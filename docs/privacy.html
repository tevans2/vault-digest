Who this applies to

Vault Digest is a personal Obsidian plugin used by its author. This policy explains what the plugin does with Google user data when the author signs in with their own Google account.

What data is accessed

  • Google Calendar events (scope calendar.events): the plugin creates, reads, updates and deletes events for tasks the user has chosen to put on their calendar.
  • Calendar list (scope calendar.calendarlist.readonly): the plugin reads the names of the user's calendars so the user can choose which one to use.

How the data is used

The data is used only to keep the user's calendar events and their Obsidian tasks aligned. It is not used for advertising, analytics, profiling or any other purpose.

Where the data is stored

All processing happens on the user's own computer. The plugin communicates directly with Google's servers. Calendar data is kept in the user's own Obsidian vault on their device. A Google refresh token is kept in Obsidian's local secret storage on the user's device. No Google user data is sent to, stored on, or shared with any server operated by the author or any third party.

Sharing and disclosure

Google user data is not sold, shared, transferred or disclosed to anyone.

Retention and deletion

Data stays on the user's device until the user deletes it. The user can revoke the plugin's access at any time at myaccount.google.com/permissions, and can disconnect from within the plugin's settings, which removes the stored token.

Google API Services User Data Policy

The plugin's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
